# Мій план життя

Статичний односторінковий планер для GitHub Pages.

## GitHub Pages

Опублікувати можна з гілки `main`, корінь репозиторію. Головний файл: `index.html`.

## GitHub Sync

У застосунку відкрий `⚙️` → `GitHub Sync` і заповни:

- `Власник GitHub`: твій username
- `Репозиторій`: назва репозиторію
- `Гілка`: `main`
- `Файл даних`: `data/life-planner-state.json`
- `Fine-grained token`: токен з правом `Contents: Read and write` для цього репозиторію

Після цього натисни `Вивантажити в GitHub`. На іншому пристрої введи ті самі налаштування й натисни `Завантажити з GitHub`.
